# YT 연습 플레이어 (웹 / 아이폰 사파리용)

서버가 필요 없는 **정적 웹페이지**입니다. 빌드 과정 없이 이 폴더를 그대로 호스팅하면 되고, PC를 켜둘 필요가 없습니다.

## 기능

| 기능 | 내 파일 | 유튜브 |
|---|---|---|
| 피치 조절 (-12 ~ +12 반음) | O | **X** (브라우저가 유튜브 소리를 가공할 수 없음) |
| 속도 조절 | O (0.25 ~ 2.00, 0.05 단위, 피치 유지) | O (유튜브 지원 단계: 0.25 단위) |
| A-B 구간 반복 (분:초 입력 / 현재 위치로 지정) | O | O |
| 즐겨찾기 (피치/속도/A-B 저장, 내보내기/가져오기) | O | O |
| 영상 화면 | - | O (공식 IFrame 플레이어) |

- 유튜브 열기: 주소 붙여넣기. 검색은 본인의 YouTube Data API 키를 넣으면 사용할 수 있습니다 (선택, 키는 이 브라우저에만 저장).
- 내 파일 열기: 아이폰의 파일 앱 / 안드로이드·PC의 파일 선택창. mp3, m4a, wav, flac 등 브라우저가 재생할 수 있는 형식.
- 즐겨찾기에 저장한 **내 파일은 이 기기(브라우저 IndexedDB)에 함께 보관**되어 다음에 바로 열립니다. 내보내기 파일에는 설정만 들어가므로, 다른 기기에서 가져온 즐겨찾기는 처음 한 번 파일을 다시 선택해야 합니다.

## 아이폰에서 쓰기

1. 호스팅된 주소를 **사파리**로 엽니다.
2. 공유 버튼 → **홈 화면에 추가**. (홈 화면 앱으로 쓰면 사파리가 7일 미사용 시 즐겨찾기 데이터를 지우는 제한을 받지 않습니다.)
3. 중요한 즐겨찾기는 가끔 **내보내기**로 백업하세요.

알아둘 점: 소리가 안 나면 옆면 무음 스위치 확인 / 곡이 너무 길면(10분 이상) 메모리 때문에 느려질 수 있음 / 화면이 꺼지거나 다른 앱으로 넘어가면 재생이 멈출 수 있음 (재생 중에는 화면 꺼짐을 막도록 요청함).

## 호스팅 (무료, GitHub Pages 예시)

1. GitHub에서 새 **public** 저장소를 만듭니다.
2. 이 폴더의 파일 전체(`index.html`, `js/`, `vendor/` …)를 업로드합니다.
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**.
4. 잠시 뒤 `https://<계정>.github.io/<저장소>/` 로 접속됩니다.

다른 정적 호스팅(Netlify Drop, Cloudflare Pages 등)도 폴더만 올리면 동일하게 동작합니다. **https 주소여야 합니다** (`index.html`을 파일로 직접 열면 유튜브와 오디오 모듈이 동작하지 않습니다).

## 로컬에서 테스트

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다.

## 구조

```
index.html / style.css        화면
js/app.js                     화면 전환, 컨트롤, 즐겨찾기 UI
js/engine.js                  내 파일 재생 (Web Audio + SoundTouch 피치/속도)
js/youtube.js                 유튜브 IFrame 플레이어 래퍼, 주소 파서
js/store.js                   즐겨찾기 (localStorage) + 음악 파일 보관 (IndexedDB)
sw.js / manifest.webmanifest  홈 화면 앱 / 오프라인 실행
vendor/                       SoundTouchJS (MPL-2.0, 원본 라이선스 포함)
```

## 동작 원리 (피치/속도)

재생 소스를 `speed`배로 돌리면 속도와 피치가 함께 바뀌는데, SoundTouch 오디오 워크릿에 같은 배속을 알려주면 그만큼 피치를 되돌려 줍니다. 여기에 반음 값을 더해 속도와 피치를 독립적으로 조절합니다. 설정 변경은 실시간으로 반영됩니다 (재처리 대기 없음).

## 검증 상태

PC 브라우저에서 실제로 측정해 확인한 항목: 440Hz 사인파 기준 +12반음 = 880Hz, -12반음 = 220Hz, +5반음·1.5배속 = 587.3Hz, 0.5/1/2배속 위치 진행률, A-B 반복 구간 유지, 일시정지/재개, 곡 끝 자동 되감기, 즐겨찾기 저장/복원/내보내기/가져오기, 유튜브 재생·속도·A-B 반복.

**아이폰 사파리 실기기에서는 아직 확인하지 못했습니다.** 특히 무음 스위치, 첫 재생 시 오디오 잠금 해제, 유튜브 영상 재생 버튼 동작은 실기기에서 확인이 필요합니다.
